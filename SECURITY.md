# Security policy

BabyNoxa is not approved for production or real-value use. Do not test against public
users or funds.

Report suspected vulnerabilities privately to the repository owner with affected
commit, component, impact, prerequisites, and a minimal reproduction. Do not include
private keys, seed phrases, credentials, personal data, or stolen funds. Avoid public
disclosure until maintainers acknowledge remediation and coordinate a safe timeline.

No bug bounty, compensation, response SLA, or safe-harbor promise exists unless a
separate written program is published by an authorized legal entity. For an active
incident, operators follow `docs/TRUST_AND_EMERGENCY.md`.
