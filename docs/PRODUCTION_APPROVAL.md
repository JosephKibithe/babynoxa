# Production launch decision

**Decision: NOT APPROVED.** This is the only safe default.

Approval may be changed only after all Phase 14 evidence is attached and reviewed:

- final immutable candidate commit, tag, source-tree and bytecode hashes;
- clean CI including configured Amoy fork and monitored lifecycle rehearsal;
- independent smart-contract audit and retest with no unresolved critical/high finding;
- external application/hosting security review;
- qualified legal, privacy, moderation, age, jurisdiction, and license review;
- verified public source, ABIs, addresses, deployment blocks, manager version, and LP policy;
- operations, incident, key-management, monitoring, support, and communications readiness.

Required signatures: contract security owner, application security owner, operations
owner, product owner, treasury/finance owner, and qualified legal/privacy reviewer.
Each must record name, role, date, candidate hash, decision, and accepted residual
risks. No automated system or single developer can grant this approval.
